# 🌐 HTML5, JavaScript e CSS

Repositório dedicado aos exercícios, atividades e projetos desenvolvidos durante os estudos de desenvolvimento web.

## 🎯 Objetivo

Aprender e praticar os fundamentos do desenvolvimento web, criando páginas e aplicações com estrutura, estilo e interatividade.

## 💻 Conteúdos

- **HTML5:** estruturação de páginas web.
- **CSS3:** estilização, layouts e personalização visual.
- **JavaScript:** lógica de programação e interatividade.
- Desenvolvimento de páginas web.
- Exercícios práticos e pequenos projetos.

## 🛠️ Tecnologias e ferramentas

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git e GitHub

## 📂 Organização

O repositório reúne códigos, exercícios e projetos desenvolvidos durante os estudos, organizados conforme as atividades realizadas.
